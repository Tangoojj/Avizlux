# tangoojj.github.io — فروشگاه نمونه‌ی آویزلوکس

نسخه‌ی نمایشی (دمو) فروشگاه آویز و لوستر، فارسی و راست‌چین، برای پیش‌نمایش طراحی.

- محصول‌ها: همان فهرست منتخب ۱۰ آویز اقتصادی (بررسی ۱۸ مهر ۱۴۰۵)؛ نام و قیمت از همان فهرست، دکمه‌ی «مشاهده» به صفحه‌ی اصلی هر کالا می‌رود.
- تصاویر: آثار تصویریِ اصیلِ ساخته‌شده برای این نمونه، متناسب با فرم هر مدل — عکس‌های فروشگاه مبدأ نیستند.
- خرید واقعی از این صفحه انجام نمی‌شود؛ سبد خرید صرفاً نمایشی است.

فایل‌ها: `index.html`، `style.css`، `app.js` (داده و منطق)، `images.js` (تصاویر جاسازی‌شده).
